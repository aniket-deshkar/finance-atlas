## Decisions

- Keep local ledger calculations and the present encrypted vault format. Device records use a separate encrypted archive and restore transaction into an empty destination namespace.
- Route reviewed chat facts to bounded, read-only ADK specialists. Use a separate search-enabled agent only for public insurance research. Keep region, pricing, authentication, and rate and budget policy at the API boundary.
- Use a toolbar launcher and focus-managed mobile navigation. Render placeholders in privacy mode instead of styling exact values.
- Generate Hosting script hashes and release metadata from the export. CI checks the same release configuration. Cloud promotion is an environment-scoped operation and requires its own credentials and release verification.
